# AI Terminal Assistant

## Overview
An AI-powered terminal assistant inspired by modern developer tools like Warp AI and GitHub Copilot CLI.

---

## Features
- Explain terminal commands
- Suggest commands from natural language
- Developer productivity workflow
- Lightweight CLI assistant

---

## Files
- `explain.py` → explains terminal commands
- `suggest.py` → suggests commands from user tasks

---

## Usage

```bash
python suggest.py
```

---

## Architecture

```text
User Task
    ↓
Command Suggestion Engine
    ↓
Terminal Command
    ↓
Command Explanation
```

---

## Example Output

```text
Suggested Command: mkdir new_folder
Explanation: Creates a new folder
```
